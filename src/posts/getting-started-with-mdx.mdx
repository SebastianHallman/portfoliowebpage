## What is MDX?

MDX lets you write **Markdown** with embedded React components. That means you can do everything you'd normally do in Markdown — headings, lists, code blocks, links — and also drop in interactive UI wherever you need it.

## Why use it for a blog?

- Write posts as plain files tracked in git
- No CMS or database needed
- Embed live demos, charts, or any React component inline
- Vite bundles everything together automatically

## A quick example

Here's some inline `code`, and a fenced block:

```js
function greet(name) {
  return `Hello, ${name}!`
}
```

And a simple list:

1. Install `@mdx-js/rollup`
2. Add it to your Vite config
3. Write `.mdx` files and import them like any module

That's the whole idea. Each post is just a file — edit it, commit it, done.
